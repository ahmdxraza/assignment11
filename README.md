# YouTube Clone

A simple **YouTube Clone website** created as an HTML and CSS assignment.
The project is designed to practice website layout, navigation, video cards, and basic styling.

## 🔗 Live Demo

[View YouTube Clone](https://ahmdxraza.github.io/youtube_clone/)

## 🛠️ Technologies Used

* HTML
* CSS

## ✨ Features

* YouTube-style layout
* Navigation bar
* Search bar
* Video cards
* Video thumbnails
* Channel information
* Responsive layout
* Simple and clean design

## 📂 Project Structure

```text
youtube_clone/
│
├── index.html
├── style.css
└── images/
```

## 🎯 Purpose

This project was created to practice:

* HTML structure
* CSS styling
* Website layout
* Flexbox
* Navigation design
* Creating reusable video cards
